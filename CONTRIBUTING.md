# Contributing to Supernova

Use the [README](README.md#build-and-test) to build and run the project. Create a branch for your change and keep the diff focused.

- Application code lives in `Supernova/`. Use Swift Testing for unit tests in `SupernovaTests/` and XCTest for UI tests in `SupernovaUITests/`.
- Run the relevant tests before opening a pull request. For a UI change, verify it on the iPhone Duo simulator and attach a screenshot.
- In your pull request, describe what changed, how you verified it, and any related issue. For bug reports, include your OS, destination, and reproduction steps.
- Use synthetic prompts in screenshots and logs. Keep API keys, signing identities, and private conversation content out of reports and commits.

Report security problems using the instructions in [SECURITY.md](SECURITY.md).
